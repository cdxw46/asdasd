# SMURF PBX

SMURF is a from-scratch enterprise PBX platform implemented in this repository without using Asterisk, FreeSWITCH, Kamailio, OpenSIPS, or any existing PBX codebase.

## Implemented architecture

SMURF is split into independent services:

- `services/sip-core`: SIP transport and signaling core
  - UDP/TCP/TLS listeners
  - SIP over WebSocket transport (`sip` subprotocol)
  - REGISTER with digest auth (MD5 / SHA-256 parsing support)
  - INVITE/ACK/BYE forwarding for registered endpoints
  - SIP methods baseline support: OPTIONS, INFO, UPDATE, REFER, SUBSCRIBE, NOTIFY, MESSAGE
- `services/pbx-core`: call-control engine
  - extensions, max-call limits, call state, CDR persistence
  - dialplan regex routing
  - ring group and queue strategy routing (round-robin, least-busy, priority, random)
  - chat/presence commands, call park/pickup primitives
- `services/pbx-events`: PBX internal event collector
  - receives internal bus events
  - stores recent event history for observability
- `services/media-core`: RTP/RTCP media service
  - RTP relay sessions
  - packet/loss/jitter stats
  - telephone-event (RFC 4733) DTMF event extraction
  - recording metadata and raw RTP capture
- `services/api-admin`: HTTPS admin/API service (default port 5001)
  - JWT auth + optional TOTP 2FA
  - admin endpoints for extensions/trunks/dialplan/presence/chat/recordings
  - dashboard metrics and CDR export (JSON/CSV/Excel)
  - OpenAPI endpoint
  - serves SPA softphone/admin UI + PWA assets
- `services/provisioning`: dedicated phone provisioning HTTP service
  - template rendering for Yealink/Snom/Fanvil/Grandstream/Polycom/Cisco
- `services/watchdog`: process supervisor that starts and restarts all services

Shared modules:

- `core/sip.py`: SIP parser/message builder/digest helpers
- `core/db.py`: relational persistence schema (SQLite)
- `core/security.py`: JWT/password and auth helper functions
- `core/bus.py`: internal JSON command bus over TCP
- `core/config.py`: centralized YAML config loader

## Ports used

Default ports in `configs/smurf.yml`:

- SIP UDP: `5060`
- SIP TCP: `5060`
- SIP TLS: `5061`
- SIP WebSocket: `5062`
- RTP range: `20000-40000` (UDP)
- Admin/API HTTPS: `5001`
- Provisioning HTTP: `8088`
- Internal command bus:
  - PBX event bus: `9100`
  - PBX command: `9101`
  - Media command: `9201`
  - SIP command: `9301`

## Installation

Run as root:

```bash
cd /opt/smurf-source   # location of this repo copy
sudo bash install.sh
```

The installer:

1. installs OS dependencies,
2. creates user/group `smurf`,
3. deploys code to `/opt/smurf`,
4. creates Python virtualenv at `/opt/smurf-venv`,
5. creates `/etc/smurf/config.yml` and TLS certificate/key if absent,
6. installs and enables systemd units,
7. enables and starts `smurf-watchdog.service`.

## Services

Systemd units:

- `smurf-watchdog.service` (primary supervisor)
- `smurf-pbx-events.service`
- `smurf-pbx-core.service`
- `smurf-media-core.service`
- `smurf-sip-core.service`
- `smurf-api-admin.service`
- `smurf-provisioning.service`

Check status:

```bash
sudo systemctl status smurf-watchdog.service
sudo journalctl -u smurf-watchdog.service -f
```

## Security controls currently present

- SIP digest challenge auth
- JWT-based API auth
- optional TOTP 2FA for admin users
- SIP per-IP rate limiting + temporary block persistence
- TLS for web/API (self-signed certificate generated by installer)
- SIP TLS listener (enabled when cert/key are present)

## Notes

- This is a full, standalone codebase for SMURF services with no PBX third-party core.
